# WorkTracker - 工作需求记录管理系统

一个极简黑白风格的工作需求管理系统，支持智能任务追踪、计时器、工作笔记、书签管理、日历热力图和 Markdown 数据持久化。

## ✨ 功能特性

### 📋 智能今日任务
- **自动任务匹配**: 根据需求的"处理时间段"自动显示当日任务
- **延单任务提醒**: 超过预期完成日期的任务自动标记并显示延期天数
- **长期需求支持**: 无时间限制的长期任务独立显示
- **全局注意事项**: 支持重要/警告/普通三种类型的提醒
- **日期选择器**: 可查看任意日期的任务列表
- **优先级排序**: 任务按优先级从高到低自动排序

### ⏱️ 任务计时器
- **工时计时**: 为每个任务启动计时器，追踪实际工作时间
- **暂停/继续**: 支持暂停和恢复计时，灵活管理工作时间
- **状态恢复**: 意外关闭页面后可恢复未完成的计时
- **超时提醒**: 超过预估时长时自动变红提醒
- **自动累计**: 工作时长自动累加到任务记录

### 📝 需求管理
- 按分类组织需求（可折叠展开）
- 支持优先级设置（高/中/低）
- 支持状态管理（待处理/进行中/已完成/已取消）
- 设置处理时间段和预计完成日期
- 预估工作时长和进度追踪（5级进度条）
- 按优先级、状态、关键词筛选

### 📝 工作笔记
- **Markdown 编辑器**: 支持实时预览的 Markdown 笔记
- **三种视图模式**: 编辑、预览、分屏模式自由切换
- **本地存储**: 笔记以 `.md` 文件保存，支持离线使用
- **自动标题提取**: 从 H1 标题自动设置笔记名称

### 🔖 书签管理
- 收藏常用网站和资源链接
- 按分类组织书签
- 支持搜索和筛选
- 一键打开链接

### 📅 日历热力图
- **工作负载可视化**: 直观显示每日任务数量
- **颜色热力图**: 不同颜色深度表示工作强度
- **日期详情**: 点击日期查看当日任务详情
- **月份导航**: 轻松切换月份查看历史数据

### 📄 Markdown 管理
- 预览每日任务的 Markdown 格式
- 复制/下载 Markdown 文件
- 一键保存到磁盘 (`data/daily_markdown/`)
- 支持查看需求列表的 Markdown

### 📊 月度报告
- 自动统计月度工作数据
- 工作天数、完成率、高优先级完成率
- 按分类统计任务数量
- 每日完成情况表格
- 自动保存报告到 `data/monthly/`

### 📈 统计分析
- 任务状态分布柱状图
- 实时统计完成率

## 🎨 设计风格

**Noir 极简黑白风格**
- 纯黑背景 (#0a0a0a)
- 白色/灰色层次分明
- 无彩色干扰，专注工作
- 优先级使用微妙的边框颜色区分

## 📁 数据存储

所有数据以 Markdown 格式存储，方便版本控制和手动编辑：

```
data/
├── requirements.md          # 需求列表（V5 格式）
├── global_notes.md          # 全局注意事项
├── bookmarks.md             # 书签数据
├── notes/                   # 工作笔记
│   └── [uuid].md
├── daily/                   # 每日任务数据 (JSON)
│   └── 2026-02-25.md
├── daily_markdown/          # 每日任务 Markdown (格式化)
│   └── 2026-02-25.md
└── monthly/                 # 月度报告
    └── 2026-02.md
```

### 需求数据格式 (V5)

```markdown
- [ ] 需求标题 | 分类 | 优先级 | 状态 | 预计完成日期 | 处理时间段 | 预估工时 | 实际工时 | 进度 | 需求类型 | 备注
```

## 🚀 安装和运行

### 1. 克隆项目

```bash
git clone https://github.com/SeaLeee/WorkTracker.git
cd WorkTracker
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 初始化数据文件

```bash
# 复制示例文件作为初始数据（可选）
cp data/requirements.example.md data/requirements.md
cp data/global_notes.example.md data/global_notes.md
```

### 4. 启动应用

```bash
python app.py
```

或直接双击 `启动.bat` (Windows)

### 5. 访问应用

打开浏览器访问: http://localhost:5000

## 🛠 技术栈

- **后端**: Python Flask
- **前端**: Vue.js 3 (CDN)
- **图表**: Chart.js
- **数据存储**: Markdown 文件（无数据库依赖）

## 📸 界面预览

应用包含八个主要视图：
1. **今日任务** - 智能显示当日需处理的任务 + 延单提醒 + 计时器
2. **全部需求** - 按分类管理所有需求（按优先级排序）
3. **书签** - 管理常用网站和资源链接
4. **笔记** - Markdown 格式的工作笔记
5. **日历** - 工作负载热力图
6. **Markdown** - 预览和导出 Markdown
7. **月报** - 月度统计和报告生成
8. **统计** - 数据可视化分析

## 📖 使用说明

### 基本操作
1. **新建需求**: 点击右上角"+ 新建需求"
2. **设置处理时间段**: 需求会在该时间段内自动出现在今日任务
3. **延单提醒**: 超过预期完成日期的任务会在"延单任务"区域显示
4. **完成任务**: 点击任务前的复选框
5. **保存 Markdown**: 在 Markdown 管理页面点击"保存到磁盘"

### 计时器使用
1. 在任务卡片上点击"▶ 开始"启动计时
2. 点击"⏸ 暂停"暂停计时，稍后可点击"▶ 继续"恢复
3. 点击"⏹ 结束"停止计时并保存工时记录
4. 如果意外关闭页面，下次打开会提示恢复未完成的计时

### 工作笔记
1. 点击顶部"📝 笔记"标签进入笔记模块
2. 点击"+ 新建笔记"创建笔记
3. 使用 Markdown 语法编写内容
4. 切换编辑/预览/分屏模式查看效果
5. 点击"💾 保存"保存笔记
